# Zyrabit — Landing curso IA soberana

Landing waitlist / early bird del curso **Despliega IA soberana en tu infra**.

Stack: **Vite + React + TypeScript + Tailwind CSS** · tipografía Funnel Display · copy en español.

## Requisitos

- Node.js 20+ (recomendado)
- npm

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre la URL que imprime Vite (por defecto `http://localhost:5173`).

## Build de producción

```bash
npm run build
```

Preview del build:

```bash
npm run preview
```

## Secciones

Nav · Hero · Problema · Solución · Para quién · Logros · Temario · Formato · Precio · Waitlist · FAQ · Cierre · Footer

La waitlist guarda entradas en `localStorage` (`zyrabit-waitlist`) y hace `console.log`. No hay backend; hay un comentario en el código donde enchufar la API real.
